# D13 - Repaso Integral del Ciclo (SQL)

Este día repasa TODOS los temas vistos en el ciclo de SQL:

| Tema | Día |
|------|-----|
| Instalación y conexión al servidor | D1 |
| CREATE DATABASE / DROP DATABASE | D2 |
| CREATE TABLE (INT, VARCHAR) | D3 |
| ALTER TABLE / DROP TABLE | D4 |
| NULL / NOT NULL | D5 |
| INSERT INTO | D8 |
| SELECT y alias (AS) | D9 |
| UPDATE / DELETE masivo | D10 |
| WHERE (=, >, <, <>) | D11 |
| AND, OR, LIKE | D12 |

## 📁 Estructura

Cada ejercicio tiene **3 archivos**:

```
EjercicioN/
├── Borrar.sql      → Borra TODO (base de datos completa)
├── Inicio.sql      → Crea la base de datos, tablas y datos iniciales
└── Ejercicio.sql   → El enunciado y el espacio para tu solución
```

## 🔄 Flujo de trabajo

1. **Ejecuta `Inicio.sql`** para preparar las condiciones iniciales del ejercicio.
2. **Escribe tu solución** en `Ejercicio.sql` y ejecútala.
3. **Si te equivocas o quieres reiniciar:**
   - Ejecuta `Borrar.sql` (limpia todo)
   - Ejecuta `Inicio.sql` de nuevo (restaura las condiciones iniciales)
   - Vuelve a intentar con `Ejercicio.sql`

## 🎯 Objetivo

Si logras resolver los 8 ejercicios sin mirar la teoría, estás listo para el examen. ¡Mucho éxito! 🎓
