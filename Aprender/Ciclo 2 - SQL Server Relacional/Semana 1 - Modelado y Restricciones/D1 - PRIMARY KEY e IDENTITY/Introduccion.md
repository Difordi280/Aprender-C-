# D1 - PRIMARY KEY e IDENTITY

Hoy estudias cómo identificar una fila sin duplicados. `PRIMARY KEY` no permite `NULL` ni valores repetidos y normalmente crea un índice para buscar con rapidez. `IDENTITY(seed, increment)` genera números al insertar, pero no reemplaza a la PK.

Al dormir debes poder distinguir identidad, unicidad y clave primaria; crear una tabla con PK; insertar sin escribir el ID y explicar por qué una PK protege la tabla.
